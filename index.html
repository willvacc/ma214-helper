Chapter 8–9

Confidence Intervals & Hypothesis Tests

Confidence Interval — the big idea

You don't know the true population mean μ. You take a sample, compute x̄, and build a range around it. That range is the CI — a bet that the true μ is somewhere inside.

Structure: x̄ ± (critical value) × (standard error). Wider CI = less precise but more confident.

σ known vs unknown

σ known → use z (rare in practice)
σ unknown → use t with df = n−1 (almost always)

Key z values: 90% → 1.645 | 95% → 1.96 | 99% → 2.576

Hypothesis Testing — 6 steps

1

State hypotheses — H₀ (null) and Hₐ (alternative)

2

Set α — usually 0.05

3

Compute test statistic — how many SEs is x̄ from μ₀?

4

Find p-value — probability of seeing your data if H₀ were true

5

Decision — reject H₀ if p-value < α

6

Conclusion in plain English

Left-tailed

Hₐ: μ < μ₀
p-value = area to LEFT

Right-tailed

Hₐ: μ > μ₀
p-value = area to RIGHT

Two-tailed

Hₐ: μ ≠ μ₀
p-value = 2 × one-tail area

Type I Error (α): Reject H₀ when true. | Type II Error (β): Fail to reject when false.

Key Formulas

CI for μ — σ unknown

x̄ ± t(α/2, n−1) × (s / √n) df = n − 1

CI for proportion p

p̄ ± z(α/2) × √(p̄(1−p̄) / n) Requires: np̄ ≥ 5 AND n(1−p̄) ≥ 5

Test statistic for μ (σ unknown)

t = (x̄ − μ₀) / (s / √n) df = n − 1

Test statistic for proportion p

z = (p̄ − p₀) / √(p₀(1−p₀) / n)
Worked Example — One-Sample t-test

Problem

A company claims batteries last 300 hours. You test 16 batteries: x̄=292, s=20. Test at α=0.05.

1

H₀: μ=300 | Hₐ: μ≠300 (two-tailed)

2

α=0.05, two-tailed → α/2=0.025 each tail

3
t = (292−300)/(20/√16) = −8/5 = −1.60 df = 15
4

From t-table df=15, two-tailed: |t|=1.60 < t₀.₀₂₅,₁₅=2.131 → p-value > 0.05

5

Fail to Reject H₀

6

Insufficient evidence at 5% level to conclude batteries last different than 300 hours.

Chapter 10

Inference for Two Populations

10.1 — Independent Means t-test

Two separate groups. Run F-test first for equal variances. Then pooled or unequal variances t-test.

10.2 — Paired Samples t-test

Same subjects measured twice. Compute dᵢ=x₁ᵢ−x₂ᵢ, then one-sample t-test on d̄.

10.3 — Two Proportions z-test

Compare p₁ vs p₂. Use pooled p̄_c under H₀: p₁=p₂.

Key decision: Independent (10.1) or Paired (10.2)? If each obs in group 1 is linked to one in group 2 → Paired. Otherwise → Independent.

F-test for Equal Variances (runs BEFORE 10.1)

H₀: σ²₁=σ²₂ vs Hₐ: σ²₁≠σ²₂. F=s²₁/s²₂, df₁=n₁−1, df₂=n₂−1.

p < α → reject H₀ → use two-sample t-test assuming unequal variances
p ≥ α → fail to reject → use pooled t-test

Prof. Gorgievski: "two-sample t-test assuming unequal variances" — NOT "Welch's t-test."

Two-sample t-test — unequal variances

t = (x̄₁ − x̄₂) / √(s²₁/n₁ + s²₂/n₂) df (Satterthwaite) = (s²₁/n₁ + s²₂/n₂)² ───────────────────────────────── (s²₁/n₁)²/(n₁−1) + (s²₂/n₂)²/(n₂−1)

Paired t-test

dᵢ = x₁ᵢ − x₂ᵢ d̄ = mean of dᵢ's s_d = std dev of dᵢ's t = d̄ / (s_d / √n) df = n − 1

Two-proportion z-test

p̄_c = (x₁+x₂)/(n₁+n₂) (pooled under H₀) z = (p̄₁−p̄₂) / √(p̄_c(1−p̄_c)(1/n₁+1/n₂)) CI uses UNPOOLED: √(p̄₁(1−p̄₁)/n₁ + p̄₂(1−p̄₂)/n₂)
Worked Example — Paired t-test

Problem

5 employees before/after training. Before: 72,68,74,65,71 | After: 75,70,78,67,74. Test if training improved scores (α=0.05).

1

H₀: μ_d=0 | Hₐ: μ_d<0 (before−after, negative=improvement)

2

d = −3,−2,−4,−2,−3 → d̄=−2.8, s_d=0.837

3
t = −2.8/(0.837/√5) = −2.8/0.374 = −7.49 df = 4
4

t₀.₀₅,₄=−2.132. t=−7.49 < −2.132 → in rejection region → Reject H₀.

Chapter 11

Inference for Variance

11.1 — One variance χ² test

H₀: σ²=σ²₀ using chi-square. Always requires normality. Right-skewed, always positive. df=n−1.

11.2 — Two variances F-test

H₀: σ²₁=σ²₂. F=s²₁/s²₂. df₁=n₁−1, df₂=n₂−1. Two-tailed needs both critical values.

Chi-square two-tailed test needs TWO critical values: χ²_α/2 (upper) and χ²_(1−α/2) (lower).

CI for one variance

[ (n−1)s² / χ²_(α/2) , (n−1)s² / χ²_(1−α/2) ]

Chi-square test for one variance

χ²_(n−1) = (n−1)s² / σ²₀ df = n − 1 Right-tail (Hₐ: σ²>σ²₀): p = area RIGHT of χ² Left-tail (Hₐ: σ²<σ²₀): p = area LEFT of χ² Two-tail (Hₐ: σ²≠σ²₀): p = 2 × min(left, right)

F-test for two variances

F = s²₁ / s²₂ df₁=n₁−1, df₂=n₂−1 Upper critical: F_(α/2, df₁, df₂) Lower critical: 1 / F_(α/2, df₂, df₁) [flip the df!]
Worked Example — Chi-square test for variance

Problem

Analyst claims variance > 280(%²). n=10, s²=361. Test α=0.05.

1

H₀: σ²≤280 | Hₐ: σ²>280 (right-tailed)

2
χ² = (9)(361)/280 = 3249/280 = 11.60 df=9
3

p-value = 0.2366 > 0.05 → Fail to Reject H₀. Insufficient evidence to support analyst's claim.

Chapter 12

Chi-Square Tests

12.1 — Goodness-of-Fit

Do observed counts match a hypothesized distribution? df = k−1.

12.2 — Test for Independence

Are two categorical variables related? Uses contingency table. df = (rows−1)(cols−1).

Core formula (both tests)

χ² = Σ (O − E)² / E sum over all cells

Always right-tailed only. Large χ² = big O vs E differences = evidence against H₀.

Expected counts — independence test

E_ij = (Row i total × Column j total) / Grand total ALL expected counts must be ≥ 5

Degrees of freedom

Goodness-of-fit: df = k − 1 (k = categories) Independence test: df = (r−1)(c−1) (r=rows, c=cols)
Worked Example — Test of Independence

Problem

Under 35: UA=174, Nike=132, Adidas=90 | 35+: UA=54, Nike=72, Adidas=78. Independent? α=0.05.

1

H₀: Independent. Hₐ: Dependent. df=(2−1)(3−1)=2

2

Row totals: 396, 204. Col totals: 228, 204, 168. Grand=600.

3
E(Under35,UA)=396×228/600=150.48 E(Under35,Nike)=134.64 ...
4
χ² ≈ 22.15 χ²₀.₀₅,₂=5.991 22.15 > 5.991 → Reject H₀

Chapter 13 · Final Focus

Analysis of Variance (ANOVA)

Why not just run multiple t-tests?

3 groups pairwise at α=0.05 inflates overall error to ~14%. ANOVA tests all groups at once, keeps α=0.05 globally.

SST = SSA (between groups) + SSE (within/error). F=MSA/MSE. Large F = factor matters.

One-Way ANOVA (13.1–13.2)

1 factor. H₀: μ₁=μ₂=...=μₖ. After rejecting H₀, use Tukey's HSD to find which pairs differ.

Two-Way ANOVA (13.3–13.4)

2 factors. Tests row effects, column effects, and interaction — three F-tests from one ANOVA.

Randomized Block Design (13.3 — no interaction, 1 obs/cell)

Factor A = treatment. Factor B = block (nuisance variable). Block absorbs variation from SSE → smaller SSE → larger F for A → more power.

Two-Way WITH Interaction (13.4 — 2+ obs/cell)

Interaction: effect of A depends on level of B.

If interaction is significant → do NOT interpret main effects alone.

3 Assumptions

  • Independence
  • Normality
  • Equal variance

Chapters 14–15 · Final Focus

Simple & Multiple Regression

The model

Sample: ŷ=b₀+b₁x | Population: y=β₀+β₁x+ε

OLS minimizes SSE=Σ(yᵢ−ŷᵢ)². Residual = actual − predicted.

Key metrics

R²=SSR/SST — % variation in y explained. Range 0–1.

Adj R² — penalizes extra predictors. Use to compare models.

s_e=√MSE — avg residual size in original units.

Slope interpretation

"For every 1-unit increase in x, y increases/decreases by b₁ on average."

Multiple: "...holding all other variables constant."

Association, not causation.

Hypothesis test for slope

H₀: β₁=0 | Hₐ: β₁≠0 | t=b₁/s_b₁ with df=n−2 (simple) or n−k−1 (multiple)

PI vs CI

CI for mean y at x — narrower.
PI for individual y at x — always WIDER (adds individual variability).
Both widen as x moves from x̄.

Assumptions — LINE

  • Linearity
  • Independence of residuals
  • Normality of residuals
  • Equal variance (homoscedasticity)

OLS formulas

b₁ = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / Σ[(xᵢ−x̄)²] b₀ = ȳ − b₁x̄

Sums of Squares

SST = Σ(yᵢ−ȳ)² total variation in y SSR = Σ(ŷᵢ−ȳ)² explained by model SSE = Σ(yᵢ−ŷᵢ)² unexplained/residual SST = SSR + SSE R² = SSR/SST = 1 − SSE/SST s_e = √(SSE/(n−2)) simple; use n−k−1 for multiple
Reading R Output — what to look for on the exam

Typical lm() output

Coefficients: Estimate Std. Error t value Pr(>|t|) (Intercept) 12.450 3.211 3.88 0.0015 ** x 2.370 0.480 4.94 0.0002 *** Residual standard error: 5.21 on 18 degrees of freedom Multiple R-squared: 0.575, Adjusted R-squared: 0.551 F-statistic: 24.4 on 1 and 18 DF, p-value: 0.0001

How to read it

b₀

Intercept=12.450. When x=0, predicted y=12.45. p=0.0015 → significant.

b₁

Slope=2.370. For every 1-unit increase in x, y increases 2.37 on average. p=0.0002 → highly significant.

R²

0.575 → 57.5% of variation in y explained. Adj R²=0.551 for model comparison.

df

18 df for error → n−2=18 → n=20. Back-calculate n from df on the exam.

Chapter 20 · Final Focus

Non-Parametric Statistics

What and when?

No distribution assumptions — uses ranks instead of raw values. Use when: clearly non-normal, small sample, or ordinal data.

Trade-off: more flexible, but less powerful. Always prefer parametric when assumptions are met.

Parametric Non-parametric equivalent Section
Two-sample t-test (independent) Wilcoxon Rank-Sum 20.1
Paired t-test Wilcoxon Signed-Rank 20.2
One-Way ANOVA Kruskal-Wallis 20.3

How ranking works

Combine all data, sort smallest to largest, assign ranks 1,2,3... Tied values get the average of the ranks they'd have occupied.

Wilcoxon Rank-Sum (20.1) 2 independent groups

H₀: Populations identical | Hₐ: Differ

1. Combine n₁+n₂ obs, rank ALL together 2. T = sum of ranks for smaller sample 3. Compare T to Wilcoxon table

Wilcoxon Signed-Rank (20.2) paired

H₀: Median difference=0

1. dᵢ = x₁ᵢ − x₂ᵢ 2. Drop zeros 3. Rank |dᵢ| 4. Assign + or − from sign of dᵢ 5. T⁺=sum(+ranks), T⁻=sum(−ranks) 6. T=min(T⁺,T⁻) → Wilcoxon table

Kruskal-Wallis (20.3) 3+ groups

Uses chi-square table (NOT Wilcoxon table).

H = [12/n(n+1)] × Σ(Rⱼ²/nⱼ) − 3(n+1) H ~ χ² df = k − 1 (k = number of groups)

Kruskal-Wallis is the ONLY non-parametric test here that uses the chi-square table.

Worked Example — Wilcoxon Rank-Sum

Problem

Group 1: 12,18,9,25 | Group 2: 21,7,30,15,11. Test if populations differ α=0.05.

1

H₀: Identical. Hₐ: Differ. n₁=4, n₂=5. Smaller=Group 1.

2
Sorted: 7,9,11,12,15,18,21,25,30 Ranks: 1,2, 3, 4, 5, 6, 7, 8, 9
3

Group 1 ranks: 12→4, 18→6, 9→2, 25→8. T=4+6+2+8=20

4

Table (n₁=4,n₂=5,α=0.05 two-tailed): reject if T≤11 or T≥29. T=20 → Fail to Reject H₀.

Step 1 — Type of data?

Categorical counts? → Chi-square (Ch 12)
Numeric outcome? → Step 2

Step 2 — How many groups?

1 group: Mean → t-test (9). Variance → χ² (11).
2 groups: Step 3.
3+ groups: ANOVA (13) or Kruskal-Wallis (20).

Step 3 — Independent or Paired?

Independent: F-test first, then two-sample t-test (10.1)
Paired: Paired t-test (10.2)
Proportions: Two-prop z-test (10.3)

Step 4 — Normality violated?

Yes → switch to non-parametric equivalent (Ch 20).

Most common exam trap: independent vs paired. Most common second trap: which chi-square formula (GOF vs independence → different df).

z* for 90% CI / α=0.10 one-tail: 1.282
z* for 95% CI / α=0.05 one-tail: 1.645
z* for 95% CI / α=0.025 two-tail: 1.960

CH 10Inference for Two Populations ▶
Equality of Variances — Run This First
F test: F = s₁²/s₂² df₁ = n₁−1, df₂ = n₂−1
note: Put larger s² in numerator; compare to upper-tail critical value F(α/2, df₁, df₂)
Two-Sample t — Unequal Variances (Welch)
test stat: t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂)
Satterthwaite df: df = (s₁²/n₁ + s₂²/n₂)² / [ (s₁²/n₁)²/(n₁−1) + (s₂²/n₂)²/(n₂−1) ]
Pooled t-Test — Equal Variances
pooled variance: s_p² = [ (n₁−1)s₁² + (n₂−1)s₂² ] / (n₁+n₂−2)
test stat: t = (x̄₁ − x̄₂) / (s_p × √(1/n₁ + 1/n₂)) df = n₁+n₂−2
Paired t-Test
test stat: t = d̄ / (s_d/√n) df = n−1 (n = number of pairs, d_i = x₁ᵢ − x₂ᵢ)
Two-Proportion z-Test (Hypothesis Test — Pooled)
pooled p̄_c: p̄_c = (x₁ + x₂) / (n₁ + n₂)
test stat: z = (p̄₁ − p̄₂) / √( p̄_c(1−p̄_c)(1/n₁ + 1/n₂) )
Two-Proportion CI (Unpooled SE)
(p̄₁ − p̄₂) ± z(α/2) × √( p̄₁(1−p̄₁)/n₁ + p̄₂(1−p̄₂)/n₂ )
CH 11Variance Tests ▶
Chi-Square Test for One Variance
test stat: χ² = (n−1)s² / σ²₀ df = n−1
CI for One Variance
lower bound: (n−1)s² / χ²(α/2, n−1) ← divide by the LARGER χ² critical value
upper bound: (n−1)s² / χ²(1−α/2, n−1) ← divide by the SMALLER χ² critical value
F-Test for Two Variances
test stat: F = s₁²/s₂² df₁ = n₁−1, df₂ = n₂−1
upper critical: F(α/2, df₁, df₂) from F-table (upper tail)
lower critical: 1 / F(α/2, df₂, df₁) ← flip df order when looking up lower bound
CH 12Chi-Square Tests ▶
Test Statistic (same formula for GOF and independence)
χ² = Σ (O − E)² / E
Expected Counts
independence: E_ij = (Row_i total × Col_j total) / n
GOF: E_k = n × p_k (hypothesized proportion for category k)
Degrees of Freedom
Goodness-of-Fit: df = k − 1 (k = number of categories)
Independence: df = (r−1)(c−1) (r = rows, c = cols)
Assumption Check
rule of thumb: All expected counts E_ij ≥ 5
CH 13ANOVA ▶
One-Way ANOVA
partition: SST = SSA + SSE
df: df_A = k−1 df_E = n−k df_T = n−1 (k = # groups, n = total obs)
mean sq: MSA = SSA / (k−1) MSE = SSE / (n−k)
F statistic: F = MSA / MSE ~ F(k−1, n−k)
Two-Way ANOVA with Interaction
setup: Factor A has r levels, Factor B has c levels, w observations per cell
df_A: r − 1
df_B: c − 1
df_AB: (r−1)(c−1)
df_E: rc(w−1)
F tests: F_A = MSA/MSE F_B = MSB/MSE F_AB = MSAB/MSE
Randomized Block Design
df_Treatment: k − 1 (k = # treatments)
df_Block: r − 1 (r = # blocks)
df_Error: (k−1)(r−1)
Tukey's HSD — Post-Hoc Multiple Comparisons
HSD: q(α, k, df_E) × √(MSE / n_j)
reject: |x̄_i − x̄_j| > HSD
table: Studentized range table — look up q with k groups and df_E degrees of freedom
CH 14–15Regression ▶
OLS Estimates
slope: b₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)² = SS_xy / SS_xx
intercept: b₀ = ȳ − b₁x̄
Model Fit
partition: SST = SSR + SSE
R²: R² = SSR/SST = 1 − SSE/SST
Adj R²: 1 − [ (1−R²)(n−1) / (n−k−1) ] (k = # predictors; use for multiple regression)
s_e: √(SSE/(n−2)) [simple] or √(SSE/(n−k−1)) [multiple]
t-Test for Slope
t = b₁ / s_{b₁} df = n−2 [simple] or n−k−1 [multiple]
Interval Estimates at x*
CI for mean response (narrower): ŷ ± t × s_e × √( 1/n + (x*−x̄)²/SS_xx )
PI for individual obs (wider): ŷ ± t × s_e × √( 1 + 1/n + (x*−x̄)²/SS_xx )
key difference: PI adds "+1" under the radical → always wider than the CI at same x*
CH 20Non-Parametric Tests ▶
Wilcoxon Rank-Sum Test — Two Independent Samples
Step 1: Combine both samples, rank all n₁+n₂ values (average tied ranks)
Step 2: W = sum of ranks for the group with smaller n
Step 3: Compare W to Wilcoxon rank-sum table critical values
Large n: μ_W = n₁(n₁+n₂+1)/2 σ_W = √(n₁n₂(n₁+n₂+1)/12) z = (W−μ_W)/σ_W
Wilcoxon Signed-Rank Test — Paired / One-Sample
Step 1: Compute differences d_i = x₁ᵢ − x₂ᵢ
Step 2: Drop all d_i = 0 (reduce n accordingly)
Step 3: Rank |d_i| from 1 to n (average ties)
Step 4: T⁺ = sum of ranks where d_i > 0 T⁻ = sum of ranks where d_i < 0
Check: T⁺ + T⁻ = n(n+1)/2
Step 5: T = min(T⁺, T⁻)
Step 6: Reject H₀ if T ≤ critical value from Wilcoxon signed-rank table
Kruskal-Wallis Test — k ≥ 3 Independent Groups
H = [ 12 / (n(n+1)) ] × Σⱼ (Rⱼ² / nⱼ) − 3(n+1)
n = total observations Rⱼ = rank sum for group j nⱼ = group j sample size
dist: H ~ χ²(k−1)

Variable Index

Symbol Meaning Context / Notes Ch
μ Population mean The true unknown average we're trying to estimate or test. Never known exactly — we estimate it with x̄. 8–9
μ₀ Hypothesized population mean The specific value of μ stated in H₀. Used in the denominator of the t test statistic. 9
μ_d Population mean of differences Used in paired t-test. H₀: μ_d = 0 means no difference on average. 10.2
σ Population standard deviation Almost always unknown. If known → use z. If unknown → use t. 8–9
σ² Population variance The true spread of the population. Tested with χ² (one variance) or F-test (two variances). 11
σ²₀ Hypothesized population variance The specific value of σ² stated in H₀ for the chi-square variance test. 11
α Significance level Probability of Type I error. Usually 0.05. You set this before running the test. Reject H₀ when p-value < α. All
β Probability of Type II error Failing to reject H₀ when it's false. Harder to control. Not directly set by you. 9
β₀ True population intercept The y-intercept in the true regression model y = β₀ + β₁x + ε. Estimated by b₀. 14
β₁ True population slope The slope in the true regression model. H₀: β₁=0 means x has no linear relationship with y. Estimated by b₁. 14
ε Error term (regression) The random noise in y = β₀ + β₁x + ε. Assumed normally distributed with mean 0. 14
χ² Chi-square test statistic Used for variance tests (Ch 11) and goodness-of-fit / independence tests (Ch 12). Always positive, right-skewed. 11–12
x̄ Sample mean Average of your sample data. Point estimate for μ. Used in every t-test and CI for the mean. All
s Sample standard deviation Measure of spread in your sample. Used in SE = s/√n. Square it to get s². All
s² Sample variance Square of sample std dev. Used to test σ². In ANOVA, each group has its own s². All
s_d Std dev of differences Standard deviation of the dᵢ values in a paired t-test. Not the same as s for either group. 10.2
s_e Standard error of the regression s_e = √MSE = √(SSE/(n−2)). Average residual size in original units. Smaller = better fit. 14
n Sample size Total number of observations. In paired t-test, n = number of PAIRS not total obs. In ANOVA, n = grand total. All
p Population proportion True proportion in the population. Unknown. Estimated by p̄. 9, 10.3
p̄ Sample proportion x/n where x = number of successes. Point estimate for p. 9, 10.3
p₀ Hypothesized proportion The value of p stated in H₀. Used in denominator of z-test for proportion. 9
p̄_c Pooled proportion (x₁+x₂)/(n₁+n₂). Used ONLY in two-proportion z-test under H₀: p₁=p₂. NOT used for CI. 10.3
t t test statistic Number of standard errors x̄ is from μ₀. Follows t-distribution with df = n−1 (one-sample). 9–10
z z test statistic / critical value Standard normal. Used when σ known or for proportions. Key values: 1.645 (90%), 1.96 (95%), 2.576 (99%). 8–9
F F test statistic Ratio of two variances or two mean squares. F = s²₁/s²₂ (variance test) or MSA/MSE (ANOVA). Always positive. 11–13
df Degrees of freedom Controls the shape of t, χ², and F distributions. Formula differs by test — see the df tab. All
d̄ Mean of differences Average of dᵢ = x₁ᵢ − x₂ᵢ values. Used as the numerator in paired t-test. 10.2
dᵢ Individual difference (paired) dᵢ = x₁ᵢ − x₂ᵢ for each matched pair. If dᵢ = 0, drop it in Wilcoxon Signed-Rank. 10.2, 20.2
k Number of groups In One-Way ANOVA. df_A = k−1, df_E = n−k. Also used in Kruskal-Wallis: H ~ χ²(k−1). 13, 20.3
r Number of rows In Two-Way ANOVA. df_rows = r−1. 13
c Number of columns In Two-Way ANOVA. df_cols = c−1. 13
w Observations per cell In Two-Way ANOVA with interaction. w=1 → randomized block (no interaction). w≥2 → can test interaction. 13
SST Total sum of squares Total variation in y. SST = SSA + SSE (ANOVA) or SST = SSR + SSE (regression). 13–14
SSA Sum of squares between groups Variation explained by the factor (between groups). Also called SSR in some ANOVA tables. 13
SSE Sum of squares error (within) Unexplained variation within groups. In regression it's the residual sum of squares Σ(yᵢ−ŷᵢ)². 13–14
MSA Mean square between groups MSA = SSA / df_A. Numerator of F in One-Way ANOVA. 13
MSE Mean square error MSE = SSE / df_E. Denominator of F in ANOVA. Also = s_e² in regression. 13–14
b₀ Sample intercept (regression) Estimated y-intercept. b₀ = ȳ − b₁x̄. Value of ŷ when x=0. 14
b₁ Sample slope (regression) b₁ = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / Σ[(xᵢ−x̄)²]. For every 1-unit increase in x, y changes by b₁ on average. 14
ŷ Predicted y value ŷ = b₀ + b₁x. The fitted value from the regression line. Residual = yᵢ − ŷᵢ. 14
SSR Sum of squares regression Variation in y explained by the model. SSR = Σ(ŷᵢ−ȳ)². R² = SSR/SST. 14
R² Coefficient of determination % of variation in y explained by the model. Range 0–1. Always increases when adding predictors — use Adj R² to compare models. 14–15
r Correlation coefficient Measures direction and strength of linear relationship. Range −1 to +1. r² = R². Don't confuse with r = rows in ANOVA. 14
O Observed count Actual count in a cell/category from your data. Used in χ² = Σ(O−E)²/E. 12
E Expected count Count predicted under H₀. For independence: E_ij = (Row total × Col total)/n. Must all be ≥ 5. 12
T Wilcoxon test statistic Sum of ranks for smaller sample (Rank-Sum) or min(T⁺,T⁻) (Signed-Rank). Compared to Wilcoxon table, not t or F table. 20.1–20.2
T⁺ Sum of positive ranks In Wilcoxon Signed-Rank: sum of ranks where dᵢ > 0. 20.2
T⁻ Sum of negative ranks In Wilcoxon Signed-Rank: sum of ranks where dᵢ < 0. T = min(T⁺, T⁻). 20.2
H Kruskal-Wallis test statistic H = [12/n(n+1)] × Σ(Rⱼ²/nⱼ) − 3(n+1). Follows χ²(k−1). Only non-parametric test using chi-square table. 20.3
Rⱼ Sum of ranks for group j Used in Kruskal-Wallis formula. Rank all observations together, then sum by group. 20.3

df controls the critical value you look up. Getting df wrong = looking up the wrong critical value = wrong decision. Memorize these.

One-sample t-test n − 1 n is your sample size

Two-sample t (Welch) Satterthwaite formula R computes this — don't calculate by hand
Chi-square (1 variance) n − 1 Same formula as one-sample t, different distribution

Every test in this course follows the same decision rule — just the distribution and critical value changes.

Method Reject H₀ when... Notes
p-value method p-value < α Works for all tests. Most common on exams with R output.
Critical value (two-tailed) |test stat| > critical value Compare absolute value of stat to positive critical value
Critical value (right-tailed) test stat > critical value Chi-square is always right-tailed. F-test in ANOVA is always right-tailed.
Critical value (left-tailed) test stat < −(critical value) Negative critical value for left-tail t-tests

Conclusion language — exactly how to write it

Decision Correct wording Never say
Reject H₀ "There is sufficient statistical evidence at the α=0.05 level to conclude [Hₐ]" "H₀ is false" or "We proved Hₐ"
Fail to reject H₀ "There is insufficient statistical evidence at the α=0.05 level to conclude [Hₐ]" "H₀ is true" or "We accept H₀"

Which table to use

Distribution When Table
z (standard normal) σ known, or proportion tests Standard Normal Table
t σ unknown (almost always) t-Distribution Table — need df
χ² (chi-square) Variance test, GOF, independence, Kruskal-Wallis Chi-Square Table — need df
F Two variances, ANOVA F-Distribution Table — need df₁ AND df₂
Wilcoxon Rank-Sum (20.1), Signed-Rank (20.2) Wilcoxon Table — need n₁, n₂
Studentized range (q) Tukey's HSD post-hoc test q-Table — need k and df_E
